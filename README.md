# Zsh 配置

自用配置

`./home/`文件夹就是`macOS`的用户文件夹，可选用里面的配置

## brew 安装的工具

```zsh
# ==> Formulae
brew install git mise mole python-build ruby-build starship zinit
brew install bash container sevenzip
# ==> Casks
brew install --cask google-chrome firefox font-maple-mono-nf-cn font-sf-mono visual-studio-code zed@preview typora coteditor jetbrains-toolbox sf-symbols wechatwebdevtools
brew install --cask stash popclip syntax-highlight qlmarkdown keka launchos
brew install --cask tablepro proxyman github-copilot-for-xcode
brew install --cask betterdisplay cleanmymac cleanshot permute pixelsnap downie adguard ogdesign-eagle
brew install --cask crossover parallels qq tencent-meeting wechat wechatwork
```
